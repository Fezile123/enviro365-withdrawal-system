# Enviro365 Investments — Frontend

React (Vite) frontend for the withdrawal system. Talks to the Spring Boot
backend at `http://localhost:8080`.

## Run locally

```bash
npm install
npm run dev
```

Opens at http://localhost:5173. Make sure the backend is running first
(see ../backend/README or the root README).

## Build

```bash
npm run build
```

Outputs to `dist/`.
